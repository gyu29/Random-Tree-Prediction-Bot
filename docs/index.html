A gold ETF and a growth-tech stock don't move for the same reasons — so why score them with the same model?

One model, blended regimes

A single classifier trained on everything has to average away exactly the differences that make each factor category tradeable on its own terms.

02

Eight, instead

Each of the 8 categories below gets its own hybrid Random Forest + XGBoost ensemble, trained only on that category's symbols.

03

Checked, not assumed

Every one is walk-forward validated — see the methodology section for exactly what that does and doesn't prove.

Methodology

Built to survive scrutiny

Every threshold and every headline number in this project's own development log was checked against data the model never touched — including a few checks that failed the first time and got fixed, not hidden.

Chronological, per symbol, never shuffled.

  • Walk-forward, not shuffled

    Each symbol's history splits chronologically into train / validation / test. Verified: 0 of 56 symbols have any date overlap between splits.

  • Thresholds tuned blind to test

    Each category's decision threshold is selected against validation data only, then confirmed exactly once on test — never chosen by however it happens to score on the number you're about to be shown.

  • Every artifact is signed

    Model files are hash-verified and HMAC-signed before they're ever unpickled. A modified or corrupted model is refused, not silently loaded.

  • Labeling logic, checked

    The vectorized label computation is tested line-for-line against the original loop implementation it replaced, across six parameter combinations, for exact equivalence.

  • Fully reproducible

    Every model's manifest records the exact library versions, hyperparameters, and a hash of every training file used, plus the code's git commit — enough to answer "what exactly produced this model" months later.

  • Thread-safe by construction

    Training, analysis, and backtests all run through one synchronized state object, so a training run finishing can't race with an analysis mid-read of the model it's replacing.

Caught in review, not in production
Before

rates_recession included ^TNX and ^IRX — Treasury yield quotes, not prices. ^IRX went briefly negative in 2020, a real event. Computing a percentage return against a near-zero "price" produced, for that one category:

−164,000,000,000%

a reported compounded return

After

Swapped for BIL and GOVT — real, tradable ETFs. Same category, same methodology, data rebuilt, model retrained:

bounded, sane results

every number in the category is now within a plausible range
